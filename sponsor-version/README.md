Sponsor-focused version for Fecund Performance

Files in this folder:
- index.html  -> Sponsor landing page
- styles.css -> Additional CSS for sponsor pages
- script.js  -> Small JS helpers

How to use:
1. Upload your badge image to the repository at /assets/badge.png (this file will be shown in the hero). If you prefer another filename, update the <img> src in index.html.
2. Add gallery images at /assets/gallery1.jpg, /assets/gallery2.jpg, etc. The gallery uses those paths.
3. Optionally upload sponsor-pack.pdf to /sponsor-version/sponsor-pack.pdf. A placeholder link is included.
4. To publish this version as the live site root, you can either:
   - Replace the root index.html with this sponsor-version/index.html (I can do that for you), or
   - Point GitHub Pages to serve the sponsor-version/index.html (rename to index.html) or deploy via Netlify and set the publish directory appropriately.
